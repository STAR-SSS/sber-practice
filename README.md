# СберПрактика 

Демонстрационное SPA-приложение, разработанное в рамках производственной практики ПАО Сбербанк.

---

## Технологии

- **React 18** — библиотека для построения пользовательского интерфейса
- **Redux Toolkit** — управление глобальным состоянием (авторизация)
- **React Router v6** — клиентская маршрутизация
- **The Movie Database API** — источник данных о фильмах


---

## Страницы

| Маршрут | Описание |
|---|---|
| `/` | Главная страница |
| `/login` | Страница авторизации |
| `/movies` | Список популярных фильмов |
| `/profile` | Профиль пользователя (защищённый маршрут) |

---

## Функциональность

- **Авторизация** — вход по логину и паролю (Admin / 12345), состояние хранится в localStorage
- **Защищённый маршрут** — страница профиля недоступна без авторизации, происходит редирект на `/login`
- **Список фильмов** — загрузка популярных фильмов из TMDB API с постерами и рейтингами
- **Поиск фильмов** — поиск по названию через TMDB API
- **Смена темы** — переключение между светлой и тёмной темой с сохранением выбора в localStorage
- **Redux** — глобальное хранилище для управления состоянием авторизации

---

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start
```

Приложение откроется по адресу [http://localhost:3000](http://localhost:3000)
